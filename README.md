## Structure

Each language has its own directory with difficulty subdirectories (`8kyu`, `7kyu`, etc.).
Solutions are located in `solution/` and tests in `test/`.

## Running Tests

Use the root `test.sh` script to run tests or update this dashboard:

```bash
./test.sh python      # Run Python tests
./test.sh typescript  # Run TypeScript tests
./test.sh update      # Update this README
```
